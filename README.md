📊 AI Job Market Analyzer

AI Job Market Analyzer is a data analysis dashboard that explores trends in AI-related job postings. The project analyzes job roles, skills, salaries, and locations using Python and interactive visualizations.

🚀 Project Overview

The goal of this project is to analyze Artificial Intelligence job market trends using a dataset of AI job postings.

This dashboard helps users understand:

Most in-demand AI skills
Top hiring companies
Job location trends
Salary distribution
Experience requirements

The results are visualized through an interactive dashboard built using Python and Streamlit.
